Engineering decisions

A smaller surface with stronger boundaries.

Authentication
Anonymous first; optional Google credential link later.
Database
Same Firebase project and legacy Applications documents.
Interface
Semantic Svelte/HTML/CSS; no essential canvas or WebGL.
Testing
Firebase emulators, pinned Chromium, zero-pixel Linux baselines.
Previews
PR-specific URL; fixture mode by default; production writes forbidden.
Rollback
Hosting release switch; no catalogue migration to undo.
