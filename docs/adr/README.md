# Architecture decision records

ADRs capture decisions that are expensive to reverse or easy to accidentally
undo. Status values are Proposed, Accepted, Superseded, or Rejected.

- [0001: Silent anonymous-only Firebase authentication](0001-anonymous-first-auth.md)
- [0002: Preserve the legacy catalogue through an adapter](0002-legacy-catalogue-adapter.md)
- [0003: Semantic DOM/CSS omnidirectional ring](0003-semantic-dom-ui.md)
- [0004: Fixed-table emulator-only deterministic E2E](0004-deterministic-e2e.md)

Changing an accepted decision requires a new ADR that links to and supersedes
the old record.
